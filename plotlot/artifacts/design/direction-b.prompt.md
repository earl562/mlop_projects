# PlotLot Direction B ImageGen Prompt v1

Use case: ui-mockup
Asset type: desktop visual reference for a parcel-first land feasibility application
Primary request: Create a single 1440 by 900 desktop application screen for “PlotLot”, a serious parcel atlas and evidence dossier for residential land feasibility. The parcel, its authoritative identifiers, and source records are the dominant navigation model. Show a calm, precise, municipal-archive-meets-modern-product interface—not a generic SaaS dashboard, command center, deal pipeline, chat app, or luxury real-estate site.
Scene/backdrop: a large quiet parcel map at left with subtle lot lines, a selected interior parcel, a short APN-like identifier in a compact header, and no readable street address. A dossier rail at right contains source-record rows with status and citation markers.
Subject: selected parcel dossier with map, APN / folio identifier, jurisdiction coverage badge, zoning and dimensional facts, constraints, survey/plat source, evidence replay timeline, capacity and purchase-ceiling cards.
Style/medium: high-fidelity editorial product mockup, restrained cartographic ink palette, warm archival paper, charcoal, slate blue, oxidized copper status accent, narrow hairlines, intelligent tabular typography, lightly textured map fill. The interface should feel like a physical municipal evidence folder unfolded next to a cadastral map.
Composition/framing: 1440 by 900 landscape. Fixed top locator bar. Left map canvas roughly 58 percent wide; center parcel dossier roughly 27 percent; narrow evidence spine roughly 15 percent. In the center, the selected parcel identity and feasibility summary outrank all other content. The map is operationally useful but never decorative. Use empty breathing room, clear layer hierarchy, and fine-grained data density.
Lighting/mood: daylight through archive paper; sober, careful, investigatory.
Color palette: off-white paper, charcoal type, quiet slate blue, pale cadastre gray, one oxidized copper warning. No purple gradients. No beach, palm, coastal, luxury, residential lifestyle imagery.
Text (verbatim): "PlotLot"; "Parcel dossier"; "Coverage: Miami-Dade private beta"; "Zoning"; "Setbacks"; "Capacity"; "Evidence replay"; "Purchase ceiling"; "Needs verification". Use only these short labels and avoid long prose, addresses, logos, client names, or personal data.
Constraints: information hierarchy must make parcel/APN/folio and source evidence feel primary. Show source-record provenance and a bounded grounded-analysis note. Include a restrained warning state for a missing or municipality-conditional record. Use generic/redacted identifiers only. Render actual interface elements—not a photo of a screen. No personal information, no exact addresses, no countywide availability claim.
Avoid: generic AI chat canvas, chatbot bubble, CRM deal stages, command-center cards, neon gradients, glossy glass, luxury or beach clichés, people, palm trees, houses as hero imagery, watermark, nonsense text, illegible data walls, screenshot inside a device frame.
